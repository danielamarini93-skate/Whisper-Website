# Whisper website

Design-system code for [whisper-system.net](https://whisper-system.net/) (WordPress + BeTheme), built from the [Whisper UI Kit](https://claude.ai/artifact/NtwPqdoFv5wqadi8EXvPx1).

- [`wordpress/betheme-child-whisper/`](wordpress/betheme-child-whisper/README.md): a BeTheme child theme. It loads the kit's tokens and components as plain CSS, a BeTheme adapter (`wb-` classes for BeBuilder elements), a small script for menus and accordions, copy-paste HTML snippets and a demo page.
- [`wordpress/tools/build_kit_css.py`](wordpress/tools/build_kit_css.py): regenerates `whisper-kit.css` after the kit changes.

Start with the theme's README: install steps, the BeTheme Theme Options to set, and the full class reference.
